1. PNG파일
	-> 원본 이미지 크기를 얻을 파일
	-> 2의 거듭제곱 이거나 최소 4의 배수 크기
	-> 2의 거듭제곱으로 하기엔 너무 여백이 낭비된다 싶으면 4의 배수로 잡기  

2. DDS파일
	-> 밉맵용으로 들어갈 파일
	-> 반드시 2의 거듭제곱 크기+ DXT5 압축 + 밉맵 생성 파일 
	-> PNG파일의 이미지를 2의 거듭제곱으로 바꾸기 
	-> 좌상단 기준 캔버스 크기를 늘려서 여백으로 2의 거듭제곱으로 맞추기 

3. DDS파일 만드는 방법
DX깔면 설치되어있는 DirectX Texture Tool로 
Format 탭 - 
	1. 밉맵 미리 생성하기 : Generate Mip maps
	2. 압축하기 : Change Suface Format - DXT5

4. 같은 파일 명이면서 확장자만 다르게 하여 같은 경로에 파일을 넣어주세요.

>> 같은 경로 + 같은 파일명 + 확장자 ( PNG , DDS ) << 

5. PNG가 2의 거듭 제곱이면서 DDS와 크기가 동일하면 PNG은 따로 넣을 필요 없음 (이런 경우 DDS파일만 넣어도 됨)
